# Wonders of the World

This website is about the Seven Wonders of the World. It showcases information, images, and downloadable files for each wonder. The website is designed to be simple, user-friendly, and easy to navigate.

## **1. Pages Included**

1. **Home (index.html):** Provides an overview of the website and links to other sections.  
2. **Plan Your Visit (planVisit.html):** Helps users plan trips to explore the wonders.  
3. **Gallery (gallery.html):** Displays images of the wonders with interactive viewing.  
4. **About (about.html):** Explains the purpose and features of the website.  
5. **Downloads (downloads.html):** Offers Word documents containing the history of each wonder. Users can download files directly from this page.  
6. **Sitemap (sitemap.html):** Allows easy navigation to all pages of the website.  
7. **Contact Us (contactUs.html):** Enables users to send messages or provide feedback.

## **2. Technologies Used**

- **HTML:** Structured content for each page.  
- **CSS:** Each page has a dedicated CSS file for styling (e.g., `gallery.css` for `gallery.html`).  
- **JavaScript:**  
  - `app.js` handles interactive features across the site, including the gallery.  
  - `header-footer.js` manages consistent header and footer elements across all pages.  
- **Assets:** CSS, JS, downloads, and documentation are organized in separate folders for clarity and maintainability.

## **3. Documentation**

- The `documentation` folder contains `eProject.pdf` with complete project details.  
- The `downloads` folder contains Word files for the history of each wonder, which can be downloaded from the website.

## **4. Project Summary**

This website provides a simple and interactive way for users to explore the Seven Wonders of the World. Each page is styled individually for readability and visual appeal, while shared scripts ensure consistent behavior across the website. Users can view images, read detailed history, plan visits, and download resources easily.
